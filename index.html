注

指标口径与名词说明

名词含义
PV（Page View）访问 / 行为次数，同一人多次触发会重复计数。如「QQ秀点赞 PV」= 点赞动作的总次数。
UV（Unique Visitor）去重人数，同一人多次触发只算 1 个。如「QQ秀点赞 UV」= 发生过点赞的人数。
DAU（Daily Active Users）日活跃用户数。「形象创建新用户 DAU」= 当天创建形象的新用户人数。
CI（Confidence Interval）置信区间。区间若包含 0，说明涨跌可能只是随机波动 → 判定为不显著；区间不含 0 才算显著。
主态资料卡用户查看自己的资料卡（主态曝光 = 自己看自己的次数 / 人数）。
客态资料卡用户查看他人的资料卡（客态曝光 = 看别人 / 被别人看的次数 / 人数）。
宽口径（四月）分流发生在「点击头像」这一步，覆盖圆形头像 + QQ秀形象全部用户 → 接近大盘真实影响。
窄口径（六月）分流只发生在「点击 QQ秀形象」这一步，仅统计被半屏直接影响的人群 → 是影响的放大值 / 上限，并非大盘真实损耗。
总活跃净增资料卡点赞 + QQ秀点赞合计的去重活跃。六月 880,241 → 907,766，净增 +27,525（+3.13%），即资料卡点赞的小幅流失被 QQ秀点赞增量完全覆盖并超出。
显著 / 不显著「显著」= 统计上可确认的真实差异；「不显著」= 涨跌在误差范围内，不能认定为损失或收益，可视为无影响。
